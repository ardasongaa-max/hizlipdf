# HızlıPDF

Minimalist, modern ve doğal bir arayüze sahip, tarayıcı tabanlı kitap arama uygulaması.

## Kurulum ve GitHub Pages Aktifleştirme Adımları

1. Bu projeyi bir GitHub repository'sine yükleyin (`main` branch).
2. Repository ayarlarına (**Settings**) gidin.
3. Sol menüden **Pages** sekmesine tıklayın.
4. **Build and deployment** altında **Source** kısmını **GitHub Actions** olarak seçin.
5. Kodunuzu `main` branch'ine gönderdiğinizde otomatik olarak GitHub Actions çalışacak ve siteniz yayınlanacaktır.
